# Web Academy — Introdução ao Desenvolvimento Web

Projeto educativo desenvolvido para apresentar os conceitos fundamentais do desenvolvimento web, utilizando **HTML5, CSS3, JavaScript e Bootstrap 5.3.3**.

O objetivo é ajudar estudantes iniciantes a compreender a função de cada tecnologia e como elas trabalham juntas na construção de páginas web.

## Sobre o projeto

O Web Academy é um site educativo e interativo que apresenta explicações, exemplos de código e atividades práticas sobre as principais tecnologias utilizadas no desenvolvimento Front-End.

O projeto foi desenvolvido como material de apoio para aulas introdutórias de programação web, permitindo que os alunos aprendam tanto pela leitura quanto pela prática.

## Tecnologias utilizadas

- **HTML5:** responsável pela estrutura e organização do conteúdo.
- **CSS3:** utilizado para personalizar cores, fontes, espaçamentos e elementos visuais.
- **JavaScript:** responsável pela interatividade, pelos eventos e pelo funcionamento do quiz.
- **Bootstrap 5.3.3:** framework utilizado para criar componentes visuais e layouts responsivos.

## Funcionalidades

- Página inicial de apresentação.
- Explicações sobre HTML, CSS e JavaScript.
- Exemplos de código para cada tecnologia.
- Introdução ao Bootstrap.
- Comparação entre botões feitos com CSS e Bootstrap.
- Menu de navegação responsivo.
- Botão interativo utilizando JavaScript.
- Quiz com cinco perguntas sobre desenvolvimento web.
- Correção automática das respostas.
- Exibição da pontuação final.
- Opção para refazer o quiz.
- Interface adaptada para computadores, tablets e celulares.

## Estrutura do projeto

```text
Aula_Desenvolvimento_Web/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### Descrição dos arquivos

**index.html**

Contém a estrutura principal do site, incluindo menu, seções educativas, exemplos, botões e quiz.

**style.css**

Define a aparência personalizada da página, complementando os estilos fornecidos pelo Bootstrap.

**script.js**

Implementa a interatividade do site, incluindo o botão de mensagem, as perguntas, a verificação das respostas e a pontuação do quiz.

**README.md**

Apresenta a documentação e as instruções de utilização do projeto.

## Como executar o projeto

### 1. Requisitos

- Visual Studio Code ou outro editor de código.
- Navegador atualizado.
- Conexão com a internet para carregar o Bootstrap pelo CDN.

### 2. Abrir o projeto

Abra o Visual Studio Code e selecione a pasta `Aula_Desenvolvimento_Web`.

### 3. Executar o site

Instale a extensão **Live Server** no VS Code.

Depois:

1. Abra o arquivo `index.html`.
2. Clique com o botão direito no arquivo.
3. Selecione **Open with Live Server**.
4. O site será aberto automaticamente no navegador.

Também é possível abrir diretamente o arquivo `index.html` no navegador
