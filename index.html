Tecnologias utilizadas na Web

Cada tecnologia possui uma função importante na construção de um site.

HTML

HTML

HTML é uma linguagem de marcação utilizada para organizar o conteúdo de uma página.

Com HTML criamos títulos, textos, imagens, links, formulários e tabelas. 

<h1>Olá, mundo!</h1>
<p>Meu primeiro site.</p>
CSS

CSS

CSS é a linguagem utilizada para definir a aparência de uma página.

Com CSS alteramos cores, fontes, tamanhos, espaçamentos e layouts. 

h1 {
    color: blue;
    text-align: center;
}
JS

JavaScript

JavaScript é uma linguagem de programação utilizada para adicionar interatividade.

Com JavaScript criamos quizzes, validações, menus e funcionalidades. 

function saudacao() {
    alert("Olá, aluno!");
}

O que é Bootstrap?

Bootstrap é um framework de interface que oferece estilos e componentes prontos, como botões, menus, cartões e sistemas de organização em colunas.

Sem Bootstrap

Precisamos escrever o CSS para definir a aparência do botão. 

<button class="meu-botao">
    Clique aqui
</button>

Com Bootstrap

Utilizamos classes prontas para estilizar o botão. 

<button class="btn btn-primary">
    Clique aqui
</button>

Exemplo de interatividade

Clique no botão para executar JavaScript.
